# تطبيق معدات المنشطين — نادي جسور

تطبيق ويب عصري تفاعلي (Single Page Application) باللغة العربية (RTL) لإدارة ومتابعة معدات المنشطين في المجالس اليومية لنادي جسور.

## 🌟 الميزات الرئيسية
- **الشعار الرسمي**: إدراج شعار نادي جسور الرسمي بحجمه ونسبه الأصلية فوق عنوان التطبيق "معدات المنشطين".
- **إدارة الأيام (ما عدا الجمعة)**: دعم أيام الأسبوع (السبت، الأحد، الاثنين، الثلاثاء، الأربعاء، الخميس) وإمكانية إضافة عدد غير محدود من المجالس لكل يوم.
- **أعمدة مخصصة تفاعلية**: إمكانية إضافة وحذف أعمدة مخصصة للجدول ديناميكياً (مثل حالة المعدات، ملاحظات...).
- **بطاقات إحصائيات متطورة**:
  - إجمالي عدد المجالس.
  - عدد المنشطين النشطين.
  - أكثر الأماكن والقاعات استخداماً.
- **تصدير صورة PNG عالية الدقة**: زر لتنزيل صورة الجدول شاملة الشعار والعنوان والبيانات للمشاركة والطباعة.
- **ربط قواعد البيانات**: دعم التوصيل المباشر بـ Firebase Realtime Database و Supabase والتخزين المحلي.
