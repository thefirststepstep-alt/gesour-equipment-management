# تطبيق توزيع وإدارة معدات المنشطين — نادي جسور

تطبيق ويب عصري تفاعلي (Single Page Application) باللغة العربية (RTL) لإدارة وتوزيع ومتابعة معدات المنشطين في المجالس اليومية لنادي جسور (كلية العلوم الإسلامية – جامعة الجزائر 1).

![نادي جسور](logo.png)

## 🌟 الميزات الرئيسية

- **الهوية البصرية والشعار الرسمي**: إدراج شعار نادي جسور الرسمي بحجمه ونسبه الأصلية بشكل متموضع ومرافق لعنوان الكلية والنادي.
- **تزامن تلقائي مع Cloud Firestore**: ربط المباشر بقواعد بيانات **Firebase (Cloud Firestore)** لتخزين البيانات وهيكل الأعمدة ديناميكياً وتحديثها فورياً عبر جميع الأجهزة.
- **أعمدة ديناميكية 100% (تحكم كامل للمسؤول)**:
  - إضافة أعمدة جديدة بأي مسمى يختاره المسؤول (مثل: حالة المعدات، وقت الاستلام، وقت الإرجاع، عدد المعدات، اسم المسؤول، ملاحظات).
  - إعادة تسمية الأعمدة في أي وقت.
  - ترتيب الأعمدة (تحريك يميناً ويساراً).
  - حذف الأعمدة مع الحفاظ على سلامة البيانات.
- **تعديل مباشر داخل الخلايا (Inline Editing)**:
  - الضغط المباشر على أي خلية لتعديل محتواها فورياً دون الحاجة لفتح نوافذ، مع دعم اختصارات لوحة المفاتيح (`Enter` للحفظ، `Escape` للإلغاء).
  - إمكانية فتح نافذة تعديل الصف لإدخال البيانات بشكل موسع.
- **إدارة أيام الأسبوع**: تنظيم المجالس حسب أيام الأسبوع (السبت، الأحد، الإثنين، الثلاثاء، الأربعاء، الخميس) دون الجمعة افتراضياً، مع دعم عدد غير محدود من المجالس لكل يوم.
- **نظام طباعة رسمية برمجياً (`@media print`)**:
  - تصميم A4 أفقي (Landscape) مخصص للمستندات الإدارية الرسمية.
  - إظهار الترويسة والشعار الرسمي وتكرار عناوين الجدول في جميع الصفحات المطبوعة.
  - إخفاء الأزرار وأشرطة التحكم تلقائياً أثناء الطباعة.
- **تصدير صورة PNG عالية الدقة**: زر مخصص لتحميل صورة HD كاملة للجدول شاملة الشعار والعنوان والبيانات.
- **تصميم متجاوب وخفيف**: يعمل بسلاسة على أجهزة الكمبيوتر، اللوحات الذكية (Tablets)، والهواتف المحمولة مع شريط تمرير أفقاني سلس للداول العريضة.

## 🚀 طريقة التشغيل وتوليد التطبيق

1. افتح ملف `index.html` مباشرة في أي متصفح حديث.
2. لإعادة توليد وتحديث الملف بعد التعديل على السكريبت:
   ```bash
   node generate_build.js
   node build_app.js
   ```
